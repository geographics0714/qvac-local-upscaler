# samples/

`test-gradient.png` is a tiny generated placeholder (see
[`scripts/make-test-png.js`](../scripts/make-test-png.js)) used to smoke-test
the pipeline without needing a real photo.

Drop your own `.png`/`.jpg` files in here to try the upscaler on real images —
anything you add besides `test-gradient.png` is git-ignored, so your own
photos never end up in this public repo.
